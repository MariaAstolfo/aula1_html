Tag: Header

Utilizada para criar um cabeçalho em uma página, a mesma fica na parte superior "agrupando" diversos elementos como Log, Título introdutório e até mesmo o menu de navegação que também é uma tag (<nav>).

Tag Main

Utilizada paa defenir o conteúdo principal e dominante do corpo da página, ajudando os leitores a procurar com maior facilidade e encontrar o conteúdo principal de uma página, sem misturar com rodapés ou logotipos.

Tag Nav

Utilizada para criar uma seção de navegação no site.

Tag Section

Utilizada para agrupar conteúdos temáticos relacionados que compartilham um mesmo assunto em um documento HTML.

Tag Article

Utilizada para representar um conteúdo independente e autocontido que pode ser distribuído ou reutilizado separadamente do restante da página.

Tag Aside

Utilizada para colocar condeúdos secundários, como links, menus laterais, dicas e publicidades.

Tag Figure

Utilizada para agrupar um conteúdo visual ou autossuficiente (como foto, diagrama, gráfico, etc).

Tag Footer

Utilizada para definir o rodapé de uma página ou de uma seção.
